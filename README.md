## ✨ 核心功能

- 🖼️ **全站自定义背景**：
  - 支持输入图片直链作为全站背景。
  - **智能明暗遮罩**：亮色模式自动套白纱，暗色模式自动套黑纱。既保留壁纸氛围，又确保文字绝对清晰。
  - 自动穿透 PICKCAT 原生的白色背景层，让壁纸从缝隙中透出。
- 🖱️ **专属鼠标指针系统**：
  - 内置多套精美指针（单箭头、万圣节限定）。
  - **✨ 自定义上传**：无需折腾本地文件夹！在插件内直接选择本地 `.png` 图片，代码会自动将其压缩为完美的 `32x32` 像素并瞬间应用。
  - 完美映射各种交互状态（链接小手、文本输入、加载中等）。
- 🚀 **社区体验优化**：
  - **Kitten4 快捷入口**：在首页“创作”栏无痕注入 Kitten4 卡片，完美融合原生 UI 样式。
  - **外链新窗口**：帖子内的所有外部链接默认在新标签页打开，刷帖再也不怕走丢。
  - **视觉净化**：彻底移除首页/搜索页右下角碍眼的“大猫”装饰图。

## 📦 安装说明

由于本扩展未上架 Chrome 应用商店，请按照以下步骤手动加载：

1. 点击本仓库右上角的 **Code** 按钮，选择 **Download ZIP**，并解压到本地任意文件夹。
2. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择你解压后的文件夹。
5. 打开 [PICKCAT](https://pickcat.dao3.fun/)，点击浏览器右上角的插件图标即可开始配置！

---

## 📖 使用指南

- **设置背景**：点击插件图标，粘贴图床直链（推荐 `.jpg` / `.png` 结尾的链接），点击保存即可。如果觉得背景太花，可以开启“背景遮罩”开关。
- **自定义指针**：在“鼠标指针风格”下拉菜单中选择“✨ 自定义上传”，选择电脑里的 `.png` 图片。插件会自动将其压缩到 `32x32` 像素并立即应用，无需手动调尺寸。
