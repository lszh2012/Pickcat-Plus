> 一个由社区开发者打造的 [PICKCAT](https://pickcat.dao3.fun/) 浏览器增强扩展。
> 把社区改成你喜欢的样子：换壁纸、换指针、把布局倒过来、打字自动加喵，还能装别人做的主题和插件。

---

## ⚠️ 声明

1. **非官方工具**：本插件由社区用户自主创作，**非 PICKCAT 平台官方产品**，与官方无任何关联，无任何商业行为。
2. **开源免费**：代码完全开源，欢迎提意见、提 PR。
3. **只要一个权限**：`manifest.json` 里只声明了 `storage`（存你自己的设置）。不读 Cookie、不读账号、不埋点、不发任何统计请求。
4. **不碰你的数据**：所有设置都在本机 `chrome.storage.local` 里。创意工坊的第三方插件跑在隔离沙盒里，拿不到 `chrome.*` 和页面 DOM。

## 🛡 使用前的三句话

1. **本扩展不是点猫官方产品**，是社区作者自制的第三方工具；工坊里的主题/插件更是**第三方作者**做的，本扩展只做自动化检查，不做逐行人工审核。
2. **主题是纯数据**（背景色/指针/几条设置），不执行代码；**插件是会跑的代码**，但跑在沙盒里——看不到你的账号、Cookie、输入内容，也读不到网页。
3. 插件联网只能走扩展代发，且必须申报域名白名单；你填进插件的 Key 会按需发给**它申报的那个域名**。所以：只装你愿意相信的作者，别填你输不起的东西。

第一次打开「创意工坊」时会弹一次免责说明，需要勾选同意才能继续。任何时候都可以在工坊里一键卸载，或打开「⛑ 安全模式」全部停用。

## ✨ 功能

### 🖼️ 外观设置

- **全站自定义背景**：粘贴图床直链即可，也支持直接上传本地图片（自动压缩成 Base64 存本地）。
- **智能明暗遮罩**：读站点自己的主题标记（`class` / `data-theme` / `color-scheme`），亮色套白纱、暗色套黑纱，而不是傻看系统设置——所以你在亮色站点上不会莫名变灰。
- **专属鼠标指针**：内置 4 套（单箭头 / 两款斜切 / 南瓜），也可以上传自己的 `32×32` PNG，自动适配链接小手、文本输入等各种状态。
- **隐藏右下角大猫**：干掉那个碍眼的背景装饰。
- **Kitten4 快捷入口**：在「创作」栏无痕注入 K4 图标，样式跟原生一致。
- **倒反天罡布局**（可单独开关）：
  - 「分区」方块 → 横条列表
  - 「创作」长条 → 两列方块
- **外链新窗口**：帖子里的外链默认新标签页打开，刷帖不走丢。

### 🧩 创意工坊

扩展内置的一个小商店，分两类东西：

| 类型 | 是什么 | 怎么做的 |
|---|---|---|
| **个性主题** | 纯数据：背景 / 遮罩 / 指针 / 一整套 CSS 皮肤 | 直接写进你的设置，零代码、零网络 |
| **功能插件** | 一小段 JS，比如「AI 总结」 | 跑在隔离沙盒里，只能调用白名单 API |

内置内容：

- 🎃 **万圣夜惊魂** —— 明月、蝙蝠、幽灵剪影铺满夜色，南瓜橙描边卡片（作者：**Helen.S**）
- ✨ **AI 总结** —— 帖子页左下角点一下，把正文缩成 3–5 条要点。自带 Key，直连 DeepSeek / OpenAI / Kimi / 通义，不经过任何中转服务器。

社区清单里的示例条目（`workshop/community.json`）：

- 🌃 **暗夜霓虹**（PICKCAT Plus 示例）—— 深蓝到墨黑，暗色里最通透；**只有 `apply`、没有 CSS 文件**，是最简形态的模板
- 🌿 **薄荷海**（PICKCAT Plus 示例）—— 进一步演示「带 `cssFile` 的 CSS 皮肤包」怎么写

**安全设计**（这段是真做了的，不是话术）：

- 插件运行在 `sandbox.html` 的 iframe 里，**origin 为 `null`**，里面没有 `chrome.*`、没有页面 DOM、没有你的 Cookie。
- 插件安装前会弹窗逐条列出它要的权限，`network` 这种高危项标红。
- 联网必须走 `PickcatPlus.fetch()`，域名必须写在插件的 `hosts` 白名单里；白名单之外的请求硬拦。原生 `fetch` / `XHR` / `WebSocket` 在沙盒里被替换成会报错的桩。
- **⛑ 安全模式**：一键停用所有插件，主题不受影响。

### ⌨️ 输入增强「加喵」

- 发帖 / 评论时自动在句尾加「喵」，支持**按行**或**按句**两种粒度，认中文标点（。！？……）。
- 支持多个后缀词，可随机抽一个。
- 右下角 Toast 提示，10 秒防抖，不会跟你抢输入法。
- 整体可一键开关。

> 这块功能来自作者另一个独立插件 [pickcat-miao](https://github.com/lszh2012/pickcat-miao)，v2.1.0 起直接融合进本扩展，不用再装两个。

### 🎛️ 沉浸式设置面板

- 右侧一颗**可拖动**的悬浮球（拖到哪记到哪，靠近边缘自动吸附，刷新页面还在原地）。
- 球拖到屏幕**左半边**时，面板会自动改成从左滑出。
- 面板是 Shadow DOM 实现的，样式完全隔离，不会被任何网站 CSS 污染。

## 🤝 投稿（真的全自动）

社区投稿不需要懂 git、也不需要等我上线：提 Issue 填表就行。

```
你提交 Issue → 机器人几秒内跑完：解析 → 审计 → 写文件 → 更新清单 → 提交
             → 成功：回执 + 自动关单    → 失败：回一张「哪里不合格 / 怎么改」的对照表
改完直接编辑那条 Issue，会自动重跑，不用重新提。
```

- **主题（纯 CSS）= 真全自动。** 样式被逐条属性审计，只允许「画图」，改不了网页行为。
- **插件（JS）= 自动上架 + 事后秒撤。** JS 没法事前证明无害，所以机器只挡明显越界的写法（读 DOM、`eval`、外链、白名单外联网……）。
- **出了问题**：卡片上的 ⚑ 一按，就弹出一个填好的举报 Issue；维护者改一行 `workshop/revoked.json`，最多 10 分钟全量停用，已装的插件立刻停止运行并提示卸载。**这个开关在手机上就能用。**

上线延迟：raw 源 5 分钟、客户端清单 10 分钟（想立刻看到，点工坊里的「🌐 同步」）。

本地自检：

```bash
node tools/new-plugin.mjs 我的插件 my-plugin   # 生成模板
node tools/check.mjs --fix                    # 检查并自动补 sha256
```

完整规则见 [DEVELOPER.md](DEVELOPER.md)。

## 📦 安装

本扩展未上架 Chrome 应用商店，请手动加载：

1. 到 [Releases](../../releases) 下载最新 `PICKCAT-Plus-vX.X.X.zip`，解压到本地任意文件夹。
   - 也可以点仓库右上角 **Code → Download ZIP**（那是源码，效果一样）。
2. 打开 `chrome://extensions/`（Edge 用 `edge://extensions/`）。
3. 打开右上角 **「开发者模式」**。
4. 点 **「加载已解压的扩展程序」**，选刚才解压出来的文件夹。
5. 打开 [pickcat.dao3.fun](https://pickcat.dao3.fun/)，右边会出现一颗半透明的悬浮球，点它。

> 需要较新版本的 Chrome / Edge（Chromium 内核，Manifest V3）。

## 📖 使用指南

**打开设置**：点页面右侧那颗悬浮球。想换个位置就直接按住拖，松手会记住。

**设背景**：外观设置 → 粘贴图床直链（推荐 `.jpg` / `.png` 结尾）→ 保存。觉得太花就打开「背景遮罩」。

**换指针**：外观设置 → 鼠标指针 → 选内置样式，或选「自定义上传」传一张 `32×32` 的 PNG（插件会帮你压到这个尺寸）。

**装主题 / 插件**：创意工坊 → 点卡片上的「安装」→ 看清权限说明 → 确认。卸载会把你的背景、指针还原回安装之前的样子。

**用 AI 总结**：创意工坊 → 装「AI 总结」→ 点卡片上的「设置」→ 填 API Key（默认 DeepSeek，`sk-` 开头）→ 打开任意帖子，点左下角「✨ AI 总结」。

## 🔄 从旧版升级

> **太长不看**：外观设置会自动沿用，不用重新填；只有「加喵」的自定义后缀需要手动补一次。

v2.1.0 改了目录结构（新增 `sandbox.html` / `sandbox.js` / `workshop/`），所以**不能只点「重新加载」**，请按顺序来：

1. `chrome://extensions/` 找到旧版 → 点 **「移除」**
2. 按上面「安装」的步骤，重新加载解压后的新文件夹
3. 刷新 [pickcat.dao3.fun](https://pickcat.dao3.fun/)

### 设置要不要重新配？

| 你原本装的是 | 怎么处理 | 你要做什么 |
|---|---|---|
| **旧版 PICKCAT Plus**（v1.x） | 背景图、遮罩开关、指针样式、自定义指针，这四个存储键的名字和格式一个都没改 | **什么都不用做**，重装完设置还在 |
| **独立插件 pickcat-miao**（加喵前身） | 浏览器按扩展隔离存储，跨扩展读不到对方的设置 | 进「输入增强」把自定义后缀词重新填一次 |

### 关于加喵的迁移，说句抱歉

`chrome.storage` 是按扩展隔离的，我们没有任何技术手段去读另一个扩展（`pickcat-miao`）里存的后缀列表——唯一的办法是让你手动导出再粘贴回来，那比重新填一次还麻烦，所以这块没做自动迁移。

好消息是**默认后缀「喵」是开箱就有的**：如果你当初没动过后缀列表，那等于零损失；只有自己加过好几条自定义后缀的朋友需要再敲一遍，抱歉添麻烦了 🙇

## 🛠️ 目录结构

```text
PICKCAT-Plus/
├── manifest.json                     # 扩展配置（MV3）
├── content.js                        # 核心：设置面板 / 背景 / 指针 / 布局 / 加喵 / 工坊 UI
├── background.js                     # 唯一网络出口（插件联网只能走这里）
├── sandbox.html                      # 插件沙盒页（隔离环境，CSP 物理断网）
├── sandbox.js                        # 沙盒中继：RPC、API 注入、Worker 看门狗
├── cursors/                          # 内置鼠标指针
│   ├── style1.png  style2.png
│   └── style3.png  style6.png
├── icons/                            # 扩展图标
├── workshop/                         # 创意工坊
│   ├── builtin.json                  # 内置清单（随扩展打包）
│   ├── community.json                # 社区清单（投稿自动改这里）
│   ├── revoked.json                  # 撤回表（下架一个 id，10 分钟内全量生效）
│   └── packs/
│       ├── ai-summary.js             # AI 总结插件
│       ├── security-lab.js           # 安全实验室（13 项越权自测）
│       ├── theme-halloween.css       # 万圣夜惊魂皮肤
│       └── theme-mint.css            # 薄荷海（社区示例）
├── tools/
│   ├── validate.mjs                  # 投稿校验器（和扩展内同一套规则）
│   ├── css-audit.mjs                 # CSS 白名单审计（主题全自动上架的关键）
│   ├── publish.mjs                   # 投稿 JSON → 写文件 + 更新清单
│   ├── issue-to-submission.mjs       # Issue 表单 → 投稿 JSON
│   ├── validate-revoked.mjs          # 撤回表校验
│   ├── new-plugin.mjs                # 插件/主题模板生成器
│   └── check.mjs                     # 一条命令跑完全部检查
├── .github/workflows/
│   ├── auto-publish.yml              # Issue 投稿 → 自动上架
│   └── workshop-check.yml            # PR 校验 + workshop/ 改动自动合并
└── DEVELOPER.md                      # 开发者投稿指南
```

想投稿？看 [DEVELOPER.md](DEVELOPER.md)：`node tools/new-plugin.mjs` 生成模板 → `node tools/check.mjs --fix` 全绿 → 提 Issue（几秒后自动上架）。


没有构建步骤、没有 npm、没有依赖——`content.js` 一个文件就是全部逻辑，改完直接刷新扩展就能跑。

## 🚧 已知限制

- **倒反天罡 / Kitten4 入口依赖站点 DOM 结构**，PICKCAT 前端一改版就可能失效，需要跟着修。
- **AI 总结的正文是启发式提取的**（找 `<article>` / `main` / `prose` 容器取文本），在首页信息流这种没有明确正文的页面会抓错内容。
- **API Key 是明文存在 `chrome.storage.local` 的**。它不会离开你的机器，但能拿到你电脑的人也能看到。介意的话用单独的、限额的 Key。
- AI 总结按钮固定在左下角，暂时不能拖。
- 只适配 `pickcat.dao3.fun`，换域名要改 `manifest.json` 的 `matches`。
